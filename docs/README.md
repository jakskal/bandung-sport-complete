# docs/ — Dokumen Pendukung Bandung Sport

Folder ini isinya dokumen pendukung proyek, dikelompokkan per konteks.
Bukan sumber kebenaran rencana (itu tetap `../plan.md`), tapi bahan kerja:
sketsa layout, keputusan desain, catatan riset, dsb.

Struktur:

- `layout/` — sketsa & wireframe tampilan (list page, detail page, dst)

Aturan main:

1. Satu konteks = satu subfolder. Nama file deskriptif, lowercase, pakai `-`.
2. Sketsa boleh kasar — tujuannya *kebayang dulu apa yang mau dibangun*,
   bukan pixel-perfect. Format apapun yang cepet: ASCII, markdown, bullet.
3. Kalau implementasi real-nya udah beda dari sketsa, update sketsanya —
   dokumen basi lebih bahaya daripada nggak ada dokumen.

Catatan: rencananya folder docs ikut pindah ke repo private terpisah
(lihat `AGENTS.md`), jadi aman buat catatan internal.
